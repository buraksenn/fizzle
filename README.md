# fizzle

This repository includes Thorsten Ball's [Writing an Interpreter in Golang](https://interpreterbook.com/) book's Monkey language implementation in Rust. I've used it to both learn about interpreters more and learn Rust. 

When I've got stuck or when I did not want to write tests I took Paul Dix's same repo as a guidance https://github.com/pauldix/monkey-rust.
